# 🚀 Mobile Coding Academy - Android Learning Lab

Welcome to **Android Learning Lab**, an interactive educational application built as part of **Mobile Coding Academy**.

The goal of this project is simple:

> **Don't just explain Android concepts. Let developers experience them.**

Instead of reading about concurrency, coroutines, synchronization or architecture, developers can execute real experiments and observe what happens in real time.

---

# 🎯 Vision

Most tutorials explain APIs.

This project explains **why those APIs exist**.

Every lesson follows the same learning methodology:

```
Theory
    ↓
Problem
    ↓
Broken implementation
    ↓
Run experiment
    ↓
Observe the result
    ↓
Understand why it happens
    ↓
Apply the solution
    ↓
Compare both implementations
```

The objective is to understand the principles before memorizing frameworks or APIs.

# 📚 Learning Philosophy

This project follows one core principle:

> **Learn Principles, Not Frameworks**

Instead of teaching:

> "Use Mutex."

we first answer:

- What is Atomicity?
- Why do Race Conditions happen?
- Why is `counter++` not atomic?
- Why do we lose updates?
- Why do synchronization primitives exist?

Once the problem is fully understood, the solution becomes obvious.
